MiMo Incident Response Engine

7-Agent Architecture — Automated Security Incident Detection, Triage, Forensics, Containment & Reporting

7 Agents

  • • TelemetryAgent (10s) — collect & normalize
  • • CorrelationAgent (5s) — Sigma rules + MiMo
  • • TriageAgent (15s) — filter FP, prioritize
  • • ForensicAgent (30s) — timeline, IOCs
  • • ContainmentAgent (20s) — auto-isolate
  • • RemediationAgent (25s) — patch, clean
  • • ReportAgent (60s) — NIST reports

Tech Stack

  • • FastAPI + WebSocket (real-time)
  • • SQLite WAL mode (7 tables)
  • • MiMo v2.5 Pro (LLM reasoning)
  • • Sigma rules engine (8 patterns)
  • • Dark theme dashboard (8 tabs)
  • • AgentKernel lifecycle management
  • • Python 3.10+ asyncio

Detection Rules

  • • SSH Brute Force (credential_access)
  • • Port Scanning (reconnaissance)
  • • Malware + C2 (execution)
  • • Data Exfiltration (exfiltration)
  • • Privilege Escalation (privilege_escalation)
  • • Lateral Movement (lateral_movement)
  • • DNS Tunneling (command_and_control)
  • • Ransomware Activity (impact)
